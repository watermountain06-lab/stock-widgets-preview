# v2.1 사전 등록 변경 기록 최종안 (2026-10-14) — **승인 대기, 아직 고정 아님**

`v21_prereg.md` "변경 기록"에 덧붙일 문안이다. 사용자 결정(2026-10-14): ① 일회성은 A-2 유지 + 카드 전수 규칙 D-2, ② 보수 시나리오만 실제 성장률(B-5), ③ 연금+OPEB를 12-01 검정(A-5), ④ 정정 공시 수집기는 12-01 뒤. Codex·Fable 3라운드(Codex 3차 필수 없음). 사용자가 고정을 승인하면 아래를 `v21_prereg.md`에 옮기고 이 파일은 지운다.

- 2026-10-14 (실행 전, 126일 수익률을 보기 전 — 계기는 카드 4장 VLO·MO·PSX·LMT 검토, 사용자 결정) 다음을 덧붙인다.
  계기 사례에서 카드 마진·내재가치·판정이 바뀔 수 있음을 이미 봤다 — 사례 관찰 뒤의 추가이며, 후보·태그·예외·순서를 카드 판정이 좋아지는지로 고르지 않는다.
  12-01 전 학습 수익률 분석 금지와 주 결과의 기준판(`verdict_replay_prereg.md` 10-11 변경 기록)은 그대로다. 아래 변경의 해악 관문 통과는 경제적 타당성의 증명이 아니다.
  계기 카드 4장(VLO·MO·PSX·LMT)은 바꾸기 전 규칙의 값·판정을 함께 보고한다.

  **(1) A-2는 그대로(O1 손상·인수 IPR&D, 태그 기반).** 처분 손익 태그 되돌림(O2)은 넣지 않는다 — 캐시 449개사 점검에서 계기 사례가 안 잡혔다
  (PSX 2025 Q4 처분 이익은 후보 태그에 없음, MO 처분 태그는 연간 값만이라 분기 유도 불가, LMT 계약 손실은 태그 없음). 세전 기반 합성 영업이익 종목만으로는 움직이는 행이 적어 근거 부족이 예상됐다(Codex·Fable).

  **(2) D-2 카드 특별 항목(자료 보정 — 검정 대상 아님, 미검정 카드 예외).** 패널 전체의 같은 기준 수집이 불가능해 주 검정에 쓰지 않는다. 대신 **카드 전 종목 전수 규칙**으로 고르고 손으로 고르지 않는다:
  - 대상: 카드 전 종목의 최근 8분기 실적 보도자료(8-K 2.02 첨부, 외국 발행사는 6-K)에서 회사가 **세전 금액을 밝힌** 특별 항목. 8-K 2.02가 없는 종목은 "자료 범위 밖"으로 표시("항목 없음"과 구분).
  - 성격: 보도자료의 항목 명칭을 `label`로 그대로 적고, 고정 범주표(손상 / 처분 손익 / 계약·프로그램 손실 충당 / 소송·합의 / 기타)에 매핑한다(매핑 근거 칸 필수). 같은 범주 = 같은 성격. 범주표는 전수 표를 만들기 전에 고정한다.
  - 반복: **금액 문턱을 적용하기 전에** 최근 8분기에서 같은 범주가 나온 서로 다른 분기 수를 센다(비교 분기에 다시 실린 같은 사건은 한 번). 2개 분기 이상이면 반복으로 보고 그 범주의 항목은 모두 넣지 않는다(이 규칙으로 LMT 계약 손실 2024 Q4·2025 Q2는 제외됨).
  - 문턱: |금액| ≥ 0.1 × |그 분기 엔진 영업이익 − 항목 금액|(항목 반영 전 영업이익의 절댓값). 분모가 0이면 포함. 이익·손실에 같은 식.
  - 그 밖의 제외: 구조조정·인수 무형자산 상각, 엔진 영업이익 밖(영업외)에 있는 항목.
  - 이중 계산: O1이 채택되면, 그 분기 O1이 이미 되돌린 같은 경제적 항목(합산 태그 `GoodwillAndIntangibleAssetImpairment`로 되돌린 것 포함)은 태그 일치 여부와 무관하게 D-2에서 뺀다. 겹치는 금액을 분리할 수 없으면 그 분기 D-2 보정을 하지 않는다. 각 항목에 `tag` 칸(해당하면)과 겹침 기록을 두고, O1 채택 뒤 카드를 다시 계산한다. O1 미채택 동안은 태그 항목도 D-2로 들어간다.
  - 기록: `v2/special_items.json` — CIK·분기 시작·끝·세전 금액(이익 +, 손실 −)·항목 유형·영업이익 포함 근거·보도자료 URL·공개일(`filed`). 카드 계산은 공개일 ≤ 카드 기준일인 항목만 쓴다. 재현 코드는 이 파일을 읽지 않는다.
  - 적용 범위: 현금흐름 칸의 마진 입력(`margin_now`·`margin_2y`·`margin_5y`)만. PER·자기 이력·기본적 분석은 그대로.
  - 적용 절차: `special_items.json`(대상 카드 목록·기준일·범주표·제외 사유 포함)을 카드 영향 계산 **전에** 고정(커밋 해시)하고, 카드별 바뀌는 값·판정 목록을 보여 준다. 승인은 **전수 표 일괄(전부 적용 또는 전부 보류)**만 — 개별 항목의 제외·추가는 규칙 수정으로 변경 기록에 적고 전 종목에 다시 적용한다. 함께 보고: 이익·손실 항목 건수와 금액 합(회사가 손실 쪽을 더 밝히는지 점검). 카드에는 "회사가 밝힌 일회성 항목 제외(미검정 예외)"를 적는다.

  **(3) B-5 보수 시나리오의 성장 하한(판정에 쓰지 않는 시나리오 계산 — 검정 없이 적용).** 판정은 기본 시나리오(`sc[1]`)만 쓴다(카드 `dcfLevel`, `verdict_replay.py`, `hard_signals`).
  - 보수 출발 성장 g₀: 5년 CAGR(g, 지금 `history()` 값 — 기저효과 대체 규칙 그대로)이 결측이면 2.5%, g < 0이면 max(g, −15%), g ≥ 0이면 max(g ÷ 2, 2.5%)(지금과 같음).
  - 경로 gᵢ = g₀ + (2.5% − g₀) × i ÷ 4(i = 0~4). 보수 경로만 영구성장 하한을 풀고 기본·낙관(`fade`의 하한)은 그대로. 출력 `growth0`도 실제 값으로.
  - 보수 시나리오의 각 재투자 식에 max(식, 0)을 적용한다(0년 선행 재투자 포함 — 엔진은 i년 재투자를 다음 해 성장으로 정하므로 "재투자 식이 음수인 해"가 대상). 매출 감소를 자본 회수 현금 유입으로 세지 않는다. 기본·요구 성장·요구 마진 경로에는 적용하지 않는다(역산에는 음수 재투자가 남는다 — 한계로 적는다).
  - 한계: 0 ≤ g < 5%에서는 보수 출발 성장(2.5%)이 이력보다 높고, g = 0 경계에서 불연속이다. 보수 값은 판정에는 안 쓰이지만 카드 시나리오 범위·교차 표시에는 쓰인다.
  - B-5는 12-01 실행일 엔진에 포함된다(공통 조건 "엔진 파일을 바꾸지 않고"의 예외 — 판정 경로 `sc[1]`에 닿지 않음, `verdict_replay.py` 399~401행).
  - 기본 시나리오는 여전히 2.5% 하한이라 역성장 회사에서 기본이 이력보다 낙관적이다 — 카드 기본 설명에 적는다. 시나리오 금액을 정렬하지 않는다.
  - 적용 뒤 기본 내재가치·요구 성장·요구 마진·판정이 그대로인지 전 카드로 확인한다(엔진 커밋 해시 기록).

  **(4) A-5 연금·퇴직 후 의료(OPEB) 부족액 — 검정.** P0 지금 · P1 주주가치에서 부족액(세후)을 뺀다.
  - 태그 목록(닫힌 목록 — 밖의 태그는 쓰지 않는다):
    ① 합산 총계 `PensionAndOtherPostretirementDefinedBenefitPlansLiabilitiesCurrentAndNoncurrent`
    ② 합산 `PensionAndOtherPostretirementDefinedBenefitPlansLiabilitiesNoncurrent` + `PensionAndOtherPostretirementDefinedBenefitPlansCurrentLiabilities`
    ③ 연금 `DefinedBenefitPensionPlanLiabilitiesNoncurrent` + `DefinedBenefitPensionPlanLiabilitiesCurrent` + OPEB `OtherPostretirementDefinedBenefitPlanLiabilitiesNoncurrent` + `OtherPostretirementDefinedBenefitPlanLiabilitiesCurrentAndNoncurrent`(OPEB는 총계가 있으면 그것만)
    `…AndPostemploymentBenefitPlans…`(연금·OPEB보다 넓다)는 사용자 결정 범위(연금+OPEB) 밖이라 쓰지 않고 해당 종목 수만 보고한다. 순적립상태(`DefinedBenefitPlanFundedStatusOfPlan`)는 계획 간 상계가 있어 쓰지 않는다. 초과 적립 자산은 더하지 않는다(환급 제약 — 비대칭임을 적는다).
  - 값 고르기: 각 구성요소마다 filed ≤ 평가일 중 최신 결산일 값을 잡고, 평가일 − 결산일 > 400일이면 그 구성요소는 만료(0). 재공시로 나이를 늘리지 않는다. 공시된 0은 유효 값이다. ①·②·③ 중 **유효 구성요소의 최신 결산일이 가장 늦은 표현**을 쓰고, 같으면 ① > ② > ③. 그 표현 안에서 유효 구성요소만 더한다(결산일이 달라도 각자 400일 안이면 더함 — 부분 관측으로 보고). 유효 구성요소가 없으면 0(없음·만료로 따로 보고). 총계와 세부를 같이 더하지 않는다.
    (캐시 확인 예: LMT는 OPEB 비유동 최신 값이 2019-12라 만료 → 연금 비유동 $3,931M만, MO는 ③ 연금 비유동 $119M + OPEB 비유동 $938M(2026-06), PSX는 ② 합산 비유동 $592M(2026-06).)
  - 세후 = × (1 − 엔진 실효세율 `effective_tax`, 대체 규칙 포함 — 세전 ≤ 0이거나 0~40% 밖이면 법정 21%). 세전 차감은 민감도로만 보고.
  - 적용 위치: EV → 주주가치 단계에서 따로 뺀다. 엔진 차입금·투하자본·매출/자본은 그대로.
  - 방산(정부 계약 원가 회수 CAS를 공시하는 종목 — 목록은 실행 전 10-K 원문으로 고정: LMT·GD·NOC·RTX·LHX 후보)은 P1에 넣는다. 민감도: P1 결과와 "방산 종목만 차감하지 않은" 대조 결과를 병기. 할인율 변동으로 부족액이 해마다 흔들리는 점은 한계로 적는다.
  - 순서: A-1 → A-2 → **A-5** → A-3 → A-4(A-3의 기본 ≤ 0 집단이 A-5로 바뀌므로 앞에 둔다). A-4 비교 기준은 S0·O0·P0·N0, 뒤로 빼기는 A-3 → A-5 → A-2 → A-1.
    `verdict_structure_prereg.md`의 최종 조합 관문도 A-5를 포함한 v2.1로 본다.
