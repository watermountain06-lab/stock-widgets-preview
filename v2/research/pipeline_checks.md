# 자동 갱신 파이프라인의 데이터 점검 항목 (2026-10-05 초안)

카드 완성 3번(2026-10-05)에서 안건 표의 데이터 예외 안건을 "하나씩 고치기" 대신 **파이프라인이 매번 검사해 걸리는 것만 사람이 보는 항목**으로 모았다.
파이프라인(분기 실적 → 생성기 `build.py` 재빌드)을 만들 때 이 목록을 검사 단계로 구현한다. 검사에 걸리면 자동 반영하지 않고 확인 대기로 둔다.
각 항목 끝의 괄호는 근거 안건(`after_100_cards_agenda.md`).

## 1. 공시·태그 신선도
- **1-1 멈춘 태그(나이 상한)** — EV 구성요소(현금·단기투자·장기 채권·차입금·리스·금융리스 취득액), 감가상각, 인수 대금 태그의 마지막 값이
  최근 분기보다 200일 넘게 오래됐으면 경고하고 그 값을 쓰지 않는다(지금은 종목별 예외). (D2·D32·D53)
- **1-2 companyfacts 지연** — SEC 제출 목록(submissions)에 companyfacts보다 새 10-Q/10-K가 있으면 인라인 XBRL 보충(`ixbrl_supplement.py`)을 자동으로 켠다. 법인 교체(새 CIK)는 별칭 표. (D4)
- **1-3 실적 발표 뒤 공시 전 공백** — 8-K 실적 보도자료는 나왔는데 10-Q/10-K가 아직이면 "공시 대기"로 표시하고 갱신하지 않는다(보도자료 숫자는 문장에만). (D15)
- **1-4 결산 뒤 대형 인수** — 분기 말 뒤 인수 완료 8-K(Item 2.01)가 있으면 확인 대기(차입·EV 손입력 여부). (D60)

## 2. 값 대조 (같은 항목, 다른 출처)
- **2-1 4분기 EPS** — 연간 − 9개월로 만든 4분기 EPS가 보도자료 값과 5% 넘게(또는 2센트 넘게) 다르면 경고. 3개월 행이 있으면 그것을 우선. (D1·D56)
- **2-2 차입금 합계** — 엔진 차입금이 10-Q 재무상태표의 차입금 줄 합과 5% 넘게 다르면 경고(태그 조합 누락·단기차입금 10-K 전용 태그). (D5·D14)
- **2-3 같은 태그 다른 정의** — 매출 태그 후보끼리 같은 기간 값이 5% 넘게 다르면 경고(총매출 대 순매출). (D11)
- **2-4 여러 태그의 합** — 재고·설비투자처럼 합이 필요한 항목은 회사별 목록(`financials_sum_tags`·`overlay_feed.SUM`)과 재무상태표 합을 대조. (D6)
- **2-5 감가상각 구성** — 분기 감가상각이 연간의 1/4보다 크게 작거나(분기엔 다른 태그), 합계 ≈ 상각만·감가상각만이면 경고. 회사 고유 태그면 EV/EBITDA 결측 사유를 적는다. (D16·D22·B19)
- **2-6 세전이익 분기 태그 없음** — 세율이 법정 21%로 떨어지면 표시하고 연간 실효세율 대체 여부를 확인. (D18)

## 3. 기간·주식 수
- **3-1 분기 길이 비정형** — 12·12·12·16주(COST)처럼 분기 일수가 80~100일 밖이면 4분기 파생·53주 해 규칙 적용 여부 확인. (D7)
- **3-2 재작성 분기 섞임·공개일** — 분사·중단사업 회사는 재작성 분기와 원공시가 섞이지 않는지, 최근 4분기 합의 공개일 = 구성 분기 공개일의 최댓값인지. (D3·D35·D17)
- **3-3 다중 클래스·교환 단위** — 표지 주식 수가 클래스별이거나 교환 가능한 단위(Up-C·자회사 교환 지분)가 있으면 시가총액·EPS 주식 수가 같은 기준인지. (D8·D28·D46)
- **3-5 분사 직후 가격 급락** — 분할 기록 없이 하루에 50% 넘게 떨어지면(CTVA 2026-10-01 $77.65 → $12.57) 분사로 보고 비교군·카드 배수를 멈춘다(가격은 분사 뒤, 재무는 분사 전). (2026-10-06)
- **3-4 환율** — 외국 기업 환율 출처(ECB·연준 H.10)가 카드마다 같은 규칙인지, 조회 실패 시 멈춤. (D9)

## 4. 회사 고유 태그
- **4-1 재무상태표·손익 줄 태그 확인** — 새 종목·새 분기마다 재고·리스·매출원가·설비투자·이자비용이 표준 태그로 잡히는지, 회사 고유 태그면 어댑터 목록에 있는지. (D42·D62·D33·D44)

## 5. 비교군
- **5-1 비교군 결측 편향** — 섹터 비교군에서 배수가 빠진 종목 비율이 20%를 넘으면 경고하고 빠진 이유(태그·적자·EPS 조회 실패)를 파일에 남긴다. (C4·D12·D29)
- **5-2 비교 종목 가격 기준일** — 카드 유니버스 비교 종목은 카드 자기 이력 창 끝 날짜 종가로(2026-10-04 규칙), 차트 제목의 날짜 표기도 같게. (C5)
- **5-3 비교군 갱신 뒤 어긋남** — 비교군 파일을 고칠 때마다 `check_peer_drift.py`. (C6·D25)
- **5-4 v2 전용 카드 가격 등록** — 카드 유니버스 비교군에 들어갈 종목은 site_data 가격이 있어야 한다. (D57)

## 6. 생성기 산출물
- **6-1 판정 칸 비교** — 재빌드 전후 `extract_card_verdicts.js` 결과를 비교, 판정·표가 바뀐 카드는 확인 대기(자동 반영 안 함).
- **6-2 문장 리터럴** — `check_literals.py`로 cfg 문장의 계산값 리터럴 점검, 52주 고점처럼 변수가 없는 값은 분기마다 갱신 목록에. (E26)
- **6-3 JS 문법·렌더** — 인라인 JS 문법, 렌더 콘솔 오류, `sync_fallbacks.py` 정적 대체값 동기화.
