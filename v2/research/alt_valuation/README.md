# 다른 절대가치 방법 — 방법별 나란히 보기 (검증용 실험, 2026-10-11)

**적용하지 않는다.** 브랜치 `alt-valuation`에만 있고 카드·preview `main`·12-01 패널에 쓰지 않는다. 결과를 본 뒤 사용자와 이야기해 다음을 정한다.
계기: DCF가 판정의 현금흐름 칸을 혼자 맡아(가중 2) 시험 패널 계산 행의 약 78%가 "매우 비싸다"이고, MSFT·META 같은 대형 성장주를 놓친다는 문제(10-08 첫 논의).
사용자 요청: 중앙값 하나로 합치기 전에, 밸류에이션 표처럼 방법별 값과 등급을 따로 본다.

## 결과 보기 전에 고정한 가정
- 평가일: 학습 패널(`verdict_replay_panel.json`, F1~F4 기준판)의 2026-09 행. 가격(`px_then`)과 DCF 기본 내재가치(`base`)는 그 행 그대로.
- 할인율(요구수익률) 10% — DCF와 같다.
- **그레이엄**: √(22.5 × EPS TTM × BPS), 둘 다 양수일 때만.
- **RIM(잔여이익)**: BPS에서 출발. ROE(= EPS TTM ÷ BPS)가 10년에 걸쳐 할인율까지 선형으로 내려가고, 자본은 ROE × (1 − 배당성향)만큼 큰다. 10년 뒤 초과이익 0(잔존가치 없음). BPS ≤ 0이면 계산 안 함.
- **DDM(배당할인)**: 최근 6개 회계연도 주당 배당이 모두 양수인 종목만. 5년 배당 성장률(0~10%로 자름)로 5년, 그 뒤 2.5% 영구 성장.
- 입력: EPS TTM은 연구 경로 `pit.eps_ttm`(그날까지 공개된 마지막 값, 기간 끝이 200일 넘게 묵으면 `eps_age`로 표시만), BPS = `build_dcf.base_inputs`의 자본 ÷ 주식 수(평가일 공시 상태), 주당 배당은 SEC 회계연도 `CommonStockDividendsPerShareDeclared`(없으면 `CashPaid`)의 첫 공시값.
- 등급: DCF와 같은 문턱 — 주가 ÷ 가치 ≤ 0.7 매우 싸다, ≤ 0.9 싸다, ≤ 1.1 적정, ≤ 1.5 비싸다, 그 위 또는 가치 ≤ 0 매우 비싸다.
- 중앙값: 계산된 방법이 2개 이상일 때만, 참고 열.
- 수익률은 쓰지 않는다.

## 하지 않는 것
- 결과를 보고 가정(할인율·기간·문턱)을 바꾸지 않는다. 바꾸고 싶으면 변경 기록에 이유와 함께 적고 바꾸기 전·후를 모두 남긴다.
- 정상화 이익 PER(자기 이력 칸과 겹침)·상대가치(동종업 칸)·NAV(자료 없음)는 넣지 않는다.
- 판정·카드에 연결하지 않는다.

## 검토 (dual review, Codex·Fable)
- 산식은 README 가정대로 구현됐다(5종목 독립 재계산 일치).
- "쏠림은 방법 공통"은 상당 부분 설계가 강제한 결과다 — 네 방법 모두 현재 이익·자본·배당에 초과 수익성·성장이 몇 년 안에 사라지는 가정을 건다(그레이엄은 할인율 대신 PER 15 × PBR 1.5 고정 기준). 패널 PER 중앙값 24.5(이익수익률 4.1%).
- "원인은 10% 절대 기준"이라는 처음 해석은 틀렸다 — 할인율을 내려도 쏠림이 크게 풀리지 않는다(위 민감도, A0의 "할인율 3%에서도 42.9%").
- 현금흐름 칸을 어떻게 바꿔도 MSFT·META는 저평가(n ≥ 3)가 될 수 없다(칸을 빼도 MSFT 적정·META 적정~저평가). 바꿀 수 있는 경로는 자기 이력·동종업 칸이다.
- 중앙값 합성은 무배당 성장주를 더 불리하게 만든다(META 중앙값 = 그레이엄 값).

## 결정 (사용자, 2026-10-11)
지금은 DCF를 유지하고 다른 절대가치 방법은 판정에 더하지 않는다. "DCF가 검증돼서"가 아니라 "더 나은 대안이 검증되지 않아서"다(현금흐름 칸 시점 IC +0.014 [−0.023, +0.054]). 남은 후보는 12-01·2027-04 뒤 사전 등록으로 다룬다: 판정은 두고 표시만 — 주가가 암시하는 기대수익률·성장률 같은 연속값, 할인율 10%와 0.7배 문턱의 안전마진 이중 부과 점검, MSFT·META 유형은 설비투자가 PCR에 이중 반영되는지(A11) 먼저 확인.
