# 카드 항목별 갱신 확인 목록 (v2)

2026-09-23, 완성된 v2/NVDA 카드(2026-09-22 종가 $228.87)의 화면 값을 전부 뽑은 표다.
70장 변환(1단계)의 기준 문서이고, 3단계 파이프라인이 그대로 구현할 명세다.

"확인하는 법"은 "어제와 달라졌다"가 아니라 **오늘 종가로 독립 재계산한 값과 일치하는가**다.
밸류에이션 탭이 "뭔가 바뀌었으니" 통과했던 것이 이 칸이 없었던 결과다.

범례: **P** = 종가 · **Q** = 분기 공시 · **H** = 사람 판단 · ⚙ = **스크립트화 필요**(값을 만드는 코드 없이 손으로 박힌 값)

변수 이름은 NVDA 기준이다. 다른 카드에서는 `NVDA_`를 `{T}_`로 읽는다.

## 3단계(파이프라인 이식)에서 처리할 과제

NVDA 화면은 완성본이다. 아래는 화면을 바꾸자는 것이 아니라, 파이프라인이 이 값들을
갱신하려면 필요한 배관이다. 1단계 변환에서는 NVDA 틀을 그대로 따른다.

1. **코드가 없는 값** — 적정주가 밴드, 현재가, 등락률, 밸류에이션 탭 제목. 스크립트를 붙이지 않으면 갱신할 수 없다.
2. **같은 숫자의 출처가 둘 이상** — `MULTIPLE_DATA` 자기 막대와 `NVDA_VALUATION`, FCF 칸과 `FUND_COMPARE`, 네 곳의 다음 실적일.
3. **동종업 점수 기준일** — NVDA는 2026-08-27/09-11로 카드 주가(09-22)보다 오래됐다. "같은 날" 규칙을 매일 지키려면 피어 배수 갱신이 필요하다.
4. **HTML 대체값의 세대 차** — 헤더 요구 성장 대체값 "연 25.4%" vs JS 26.2%. 화면은 맞지만 JS가 죽으면 옛 숫자가 보인다.

## 변환하면서 정한 규칙 (AAPL, 2026-09-24)

틀(NVDA)에 되돌려 반영할 것은 **[틀]**로 표시한다. NVDA 화면은 지금 숫자로는 영향이 없다.

- **종합 평가** — 사람 판단. AAPL "고평가"(자기 이력 12.5 비싸다 · 내재가치 −60% 비싸다 · 동종업 48.0 중간).
- **할인율** — 70종목 비교 전까지 10% 고정(backlog "DCF 할인율"). Codex는 CAPM-WACC, Fable은 10% 유지 + 참고 표시.
- **비영업 투자자산에 `MarketableSecuritiesNoncurrent` 추가** (`build_dcf.py`). AAPL 장기 채권 $84.1B가 주주가치에서 빠져 있었다(기본 $125.64 → $134.03). 200일 넘게 낡은 계열은 버린다. NVDA 불변 확인.
- **순현금 = 현금 + 단기투자 + 장기 채권 − 차입금 − 리스.** 지분증권은 제외(`build_fundamental_score.net_cash`). AAPL −$2.44 → +$3.32.
- **자본배분은 현금흐름표 지급액 기준**(NVDA $19.7B·$6.0B와 같은 기준). 자본변동표의 발생 기준(AAPL $25.9B)과 섞지 않는다. 잔여 매입 한도는 공시가 없으면 칸을 뺀다.
- **이자보상배율 결측** — v1 규칙대로 0점, 칸에 "이자비용을 따로 공시하지 않아 계산할 수 없다"를 적는다.
- **[틀] 안정성 종합 진단은 규칙** — 재무건전성 축 비율에 v1 등급 단어(80 우수·60 양호·40 보통·미흡), 색 30/70. 해설 문단은 10-Q 대차대조표 사실로 쓴다.
- **[틀] 활동성 색은 DSO+DIO 규칙 유지**, CCC가 음수면 문장을 "판매 대금을 받고도 N일 동안 공급업체 돈으로 운영하는 구조"로 바꾼다. CCC 막대 눈금은 max(영업순환주기, 지급기간), 음수 구간도 그린다.
- **[틀] 금액 뒤 조사를 숫자에 기대지 않는다** — "지금 가격($X)이", "기본 시나리오($Y)를".
- **[틀] 브랜드 색 리터럴 치환** — `rgba(118,185,0,…)`·`#76b900`·`#9fdb2f`(NVDA 초록)이 차트·버튼·CCC 막대에 박혀 있다. 복제 때 종목 강조색으로 바꾼다.
- **체크포인트·산문은 1차 출처로 다시 쓴다.** 루트 카드에서 옮긴 AAPL 문장 중 CEO 승계 "9월 예정"(이미 9/1 취임)과 관세 $3.3B(출처 없음, 콜은 관세 환급 효과 +1%p)가 틀렸다.
- **적정주가 밴드 산식 검증** — NVDA로 $260~$370이 재현됨(최근 252거래일 시점별 TTM EPS로 나눈 PER의 p25·p75 × 현재 TTM EPS, $10 반올림). AAPL $300~$330.
- **직접 바꿔보기 자는 로그 눈금 유지** — 선형 눈금(점 사이 거리 = 달러 간격)을 AAPL에 시험했다가 사용자 결정으로 되돌렸다(2026-09-24). 로그 눈금에서는 할인율을 바꿔도 시나리오 사이 거리가 거의 그대로인데, 비율이 일정해서 생기는 정상 동작이다.
- **[틀] 점수 구성표(`.score-comp`) 칸은 한 줄 유지** — 900px 이하에서 한 칸이 아래 줄로 접혔다. `.sc-tiles` 줄바꿈 금지, `.sc-group`은 `flex:1 1 0; min-width:max-content`(넓을 땐 같은 폭, 좁으면) 폭이 모자라면 그룹이 통째로 다음 줄로. 520px 이하는 칸 44px·이름 9px. 390px에서 확인.
- **피어 비교 차트 값은 손 상수**(스크립트로 계산했지만 매일 갱신 안 됨) — 3단계 파이프라인 과제. 같은 날 종가·분모 직접 계산. 축 밖 값(AMZN PCR 367x)은 `excluded` + 툴팁에 실제 값.
- **[틀] 배수 위치 배지** — 백분위 50% 이상이면 "5년 중 상위 N%". 이력이 1200거래일 미만이면 이름 옆에 "최근 N년 이력"(NVDA 손값 "2024.08~ 이력" 대체).
- **[틀] 요약 격자(`.logic-grid`) 4칸 한 줄 기준 1100px → 980px** — 1100px 창에서도 2×2였다. 4칸은 박스 약 220px까지 한 줄로 버틴다(1000px 확인, 900px에서 내재가치 칸이 접힘).
- **헤더 밴드 적중 칸 (NVDA·AAPL 반영 완료)** — 라벨 "밴드 적중률 (맞은 날/센 날일, 쏠림)", 값은 비율. 쏠림은 이탈이 한쪽뿐이면 "이탈 전부 하단/상단", 양쪽이면 많은 쪽 "하단우세/상단우세". NVDA 58.3% (407/698일, 이탈 전부 하단), AAPL 75.9% (540/711일, 상단우세). 목표 80%·상하단 일수는 툴팁(2026-09-24 사용자 결정). 색은 비율 30/70. 확인: 종가가 밴드 경계 안인 날을 직접 센다.

1. **복제** — `python3 v2/clone_card.py {T}`. 이름·머리·브랜드 색(초록 리터럴 포함)을 루트 카드에서 읽어 치환한다. 남은 NVDA 흔적 목록을 출력한다.

3. **데이터 블록** — CIK가 `v2/build_activity_score.py` CIKS에 없으면 추가. 재무 파일을 redesign에서 `v2/fundamental_data/`로 복사. 순서: `fetch_eps_history` → `build_multiple_history --json v2/{T}_multiples.json` → `build_peer_score --self … --card` → `build_fundamental_score --card` → `build_activity_score` → `build_dcf`(scenarios·implied_growth로 `{T}_DCF` 작성) → `build_dcf_grid` → `build_dcf_track`.
4. **헤더 손값** — 현재가·등락·기준일, "실제 3년 +N%"(`history()['growth_3y']`), 적정주가 밴드(252거래일 시점별 PER p25~p75 × TTM EPS, $10 반올림), 종합 평가(사람 판단, 먼저 "확인 필요"로).
5. **판단 콘텐츠** — 루트 카드에서 옮기되 **문장마다 1차 출처로 다시 확인**. AAPL에서 루트 카드의 CEO 승계 "예정"(이미 끝남)·관세 $3.3B(출처 없음)가 틀렸다. 자사주 매입은 현금흐름표 기준인지 확인.
6. **틀 전용 문장 제거** — NVDA 산문(반도체 시장 규모, 56.6% 마진, 회사채 발행 등)이 그대로 남지 않았는지 `grep -i nvda`와 탭별 읽기로 확인.
7. **대체값 맞추기** — 탭을 다 채운 뒤 `python3 v2/sync_fallbacks.py {T}`(서버 필요). JS가 그린 값을 HTML 대체값에 되써 넣는다. 적용 전후 렌더 글자가 같은지 비교한다. 탭을 열 때만 채워지는 칸(`fundPeriodTitle`)은 손으로. AAPL 43곳·NVDA 13곳이 낡아 있었다(Codex).
8. **확인** — `node --check`는 문법만 본다. **다섯 탭을 실제로 열어 콘솔 에러 0건과 차트 4개(분기 실적·YoY/QoQ·매출 구성·비교)가 그려지는지** 확인한다(MSFT에서 `const revenue`의 공백이 치환으로 빠져 `constrevenue=`가 됐는데 문법 검사는 통과하고 분기 차트만 비었다). 그 밖에 `node --check`(인라인 JS), `python3 -m http.server`로 띄워 콘솔 0건. **주소에 `?v=N`을 붙여 캐시를 피한다**(수정한 NVDA가 캐시 때문에 옛 화면으로 보였다). 창 폭 1100·900·700·390에서 요약 격자·점수 구성표·헤더 네 칸 높이.
9. **탭마다 사용자 확인** — 표시 형식(라벨/값에 무엇을 둘지) 요청은 구현 전에 "라벨: … / 값: …"으로 한 줄 되물어 맞춘다.
- **[틀·반영됨] 애널리스트 등급은 `{T}_ANALYST.rating`** — "Strong Buy"가 HTML에 박혀 있었다(AAPL은 Buy). 목표가 여력이 음수면 빨강(`op-down`) — `op-up` 초록이 고정돼 AAPL −2.6%도 초록이었다.

## 내재가치 모델 교체 — 매출/자본(sales-to-capital) (2026-09-24, 사용자 결정)

- **왜** — 옛 모델은 EBITDA 마진을 고정하고 감가상각만 설비투자를 따라 올려, 투자 비용은 물리고 투자 성과는 0이었다(AMZN "현재 마진 유지" 시나리오의 영업이익률 12.1% → 7~10%, MSFT 46.8% → 38~43%, 카드 문구와 계산 불일치). 영업이익률만 고정하는 중간안은 반대로 상각이 늘수록 현금이 남고 4~5년차 순투자가 음수가 되어(Fable 지적·재계산 확인) 버렸다.
- **식** — FCF = 매출 × 영업이익률 × (1−세율) − Δ매출 ÷ 매출/자본. 잔존 재투자율 g/ROIC(한계 ROIC = 마진 × (1−t) × 매출/자본, 할인율 쪽 절반 수렴)와 같은 식이라 이음새가 없다. 마진 이력은 영업이익률.
- **시나리오** — 보수: 최근 1년 한계 효율과 평균 중 나쁜 쪽 유지 · 기본: 한계 → 평균으로 5년 회복 · 낙관: 평균. 한계 효율 = 1년간 매출 증가 ÷ (설비투자 − 감가상각 + 운전자본 증가 + 인수)(현금흐름 기준, 대차대조표 기준은 지분 평가이익·태그 공백에 흔들려 버림). 비교 시점은 **같은 분기의 1년 전 분기 공시일**(날짜 − 365일은 공시일이 하루만 어긋나도 한 분기 밀림).
- **요구 성장 → 요구 마진** — 요구 성장률이 최근 5년 실제의 3배를 넘거나 해가 없으면 `reqMode: "margin"`, 헤더·내재가치 탭·밸류에이션 위험 문장이 요구 영업이익률을 보인다(AAPL 83.4%, AMZN 28.2%).
- **비영업 자산 분리 표기** — 내재가치 탭에 "기본 $X = 사업 가치 $A + 비영업 자산 $B(주당)".
- **도구** — `v2/build_dcf_block.py {T}`가 `{T}_DCF` 블록을 통째로 만든다(손으로 옮기지 말 것 — AMZN baseEquivGrowth가 다른 입력의 값으로 남아 있던 사례). 순서: `build_dcf_block.py` → `build_dcf_grid.py` → `build_dcf_track.py --json` + 트랙 splice → 산문(시나리오 설명·위험 문장) → `sync_fallbacks.py`. margin 모드 카드의 `.reverse` 대체값은 sync가 못 맞추므로 렌더 문장을 그대로 넣는다.
- 결과(보수/기본/낙관): NVDA 157/314/596 · AAPL 119/130/139 · GOOGL 136/166/176 · MSFT 199/245/265 · AMZN 53/88/99. 할인율 10%·예측 5년(②)은 그대로 — 백로그 70종목 비교에서 다룬다.

- **통화(사용자 결정, Fable 지적 반영)** — 재무는 **대만달러 그대로**, 가격과 만나는 곳만 `v2/fx.py`가 그날 환율(연준 H.10, FRED DEXTAUS)로 바꾼다: 배수 = ADR 가격 × 그날 환율 ÷ 대만달러 재무, 주당 내재가치·순현금은 ÷ 환율로 달러 표시. 분기 평균 환율로 미리 달러 환산하던 첫 방식은 가격의 매일 환율과 섞여 PER·PBR을 최대 10% 흔들었다. 어댑터 파일의 단위 키는 "USD"지만 값은 대만달러(`_adapter.valuesCurrency`). 주식 수·EPS는 ADR 1주(=보통주 5주). 남는 차이는 ADR 프리미엄 — 배수가 대만 본주 기준보다 높고, 자기 이력 백분위에 프리미엄 변동이 섞인다.
- **대조** — 회사 발표와 일치: Q2 2026 달러 매출 $40.20B·EPS/ADR $4.31(분기 평균 환율 환산 시), 총자산 NT$9,375.65B, Q2 설비투자 NT$496.0B·영업현금흐름 NT$783.4B. TTM EPS/ADR $13.56 vs StockAnalysis $13.44.
- **Codex가 잡은 것** — 유동성 장기부채 라벨(새 서식 "Long-term liabilities - current portion") 누락으로 차입금 NT$1,674억 과소, 2019 상반기 덩어리 해의 EPS가 TTM을 엉뚱한 분기로 묶음, fetch_financials가 0짜리 ShortTermBorrowings에서 멈춤(→ DebtCurrent로 싣기), build_dcf CLI 통화 혼용.
- **트랙 주의** — TSM은 주당 가치를 시점 환율로 되돌리므로 트랙 마지막 점(공시일 환율)과 카드 블록(카드 기준일 환율)이 조금 다르다(정상).

## AVGO — 태그가 도중에 바뀐 회사 (2026-09-25)

companyfacts는 표준 태그만 모은다. 회사가 한동안 **다른 태그나 자체 태그**로 낸 기간은 조용히 비고, 값이 0이나 옛 값으로 채워진 채 계산이 돌아간다. AVGO에서 네 군데가 이랬다 — 새 카드마다 "태그 없음"과 "N일 뒤처짐" 경고를 그냥 넘기지 말 것.

- **감가상각** — 합산 태그가 2018년 두 건뿐이라 구성요소 경로로 못 갔다(EV/EBITDA "계산 불가"). 합산 태그가 2년 넘게 멈췄으면 무시(`live_combined`), 구성요소도 마지막 결산 뒤 450일이 지나면 뺀다(`dda_ttm`, 금융리스 상각 FY2024에서 멈춤).
- **무형자산 상각 2020~2025** — 자체 태그(`avgo:Amortizationofacquisitionrelated…` 두 줄)로만 냈다. `v2/adapters/avgo_amort.py`가 공시 원문(인라인 XBRL)에서 뽑아 `.sec_cache/overlay/{cik}.json`에 쓰고 `_facts`가 빈 기간만 채운다. 겹침 판단에 **공시일까지** 넣는다 — 2026년 공시가 2025년 분기를 비교 수치로 다시 실어, 기간만 보면 제때 공시된 행이 빠지고 시점 규칙이 그 분기를 버렸다. 2022년 이후 겹치는 기간은 표준 태그와 전부 일치.
- **비유동 차입금** — 총계(`LongTermDebt`) 폴백으로 채운 회사에는 더하지 않는다(처음 버전이 SPCX를 $38.3B → $75.1B로 이중 계상, Fable). 2025-08까지 `LongTermDebtAndCapitalLeaseObligations`로 냈다(VMware 인수 차입금 약 $60B가 EV·투하자본에서 빠짐). `LongTermDebtNoncurrent`가 없는 날짜에만 더한다. **GOOGL도 2020~2024 비유동 차입금 $13~14B가 같은 이유로 빠져 있었다** — 내재가치 추이 2024-10-30 점 $106.7 → $105.0 재반영. 다른 5장 불변.
- **자본** — `StockholdersEquity`가 2019-11($24.9B)에서 멈추고 비지배지분 포함 총계($99.7B)만 낸다. 포함 총계가 200일 넘게 앞서면 총계 − 비지배지분(`build_dcf.base_inputs`).
- **순이익** — 지배주주 순이익 태그가 FY2024에서 멈춰 순이익률이 비었다. 더 오래된 쪽이면 연결 순이익으로(`build_fundamental_score`).
- **[틀·8장] 표기** — 음수 순현금 "$-36.8B" → "−$36.8B"(MSFT·AMZN도 같은 버그), 반응 −0.03% "−0.0%" → "0.0%". TSM·SPCX 기본적 분석 툴팁의 "(확인 필요)" 잔재 제거.
- **내재가치 해석** — 최근 1년 매출/자본 7.61(자본이 거의 안 드는 성장)인데 평균은 0.65(VMware 영업권·무형자산이 투하자본에 있음). 보수와 낙관이 같은 0.65를 쓴다. 인수 직후 점(2024-09·12)은 낙관이 음수다 — 그때 영업이익률(27.9%, 인수 상각·구조조정으로 최저)이 2년 중앙값(43.5%)보다 낮은데 낙관은 현재 마진을 고정하고, 평균 매출/자본 0.37에 성장 20.8%면 재투자가 세후 영업이익을 넘어 FCF가 음수, ROIC 5.6% < 할인율이라 순차입금 $60B를 빼면 음수가 된다(Fable 재현). 계산 오류가 아니라 모델 구조다. 이력이 13분기뿐이라 3년·5년 CAGR은 같았다.

## META — 다중 클래스 주식·일회성 세금·재고 없는 사업 (2026-09-25)

- **주식 수** — 표지의 `dei:EntityCommonStockSharesOutstanding`을 Class A·B 차원으로만 내서 companyfacts에 시점 주식 수가 없었다(PSR·PBR·PCR·EV/EBITDA 계산 불가). `v2/adapters/cover_shares.py {T}`가 10-Q/10-K 표지의 클래스 값을 합산해 오버레이에 쓴다(파이프라인 `sec-cover · sum-of-classes`와 같은 방식, 2026-07-24 2,547,506,225주 일치). 오버레이는 행마다 `unit`을 적을 수 있게 했다. submissions의 "recent"는 1,000건뿐이라 옛 페이지(`files`)까지 읽는다. **다른 다중 클래스 종목도 이 어댑터를 쓴다.**
- **일회성 법인세(사용자 결정)** — 회사가 보도자료에서 금액을 밝힌 항목(Q3'25 +$15.93B·EPS +$6.20, Q1'26 −$8.03B·EPS −$3.13)을 `v2/tax_oneoff.json`에 적고, PER의 TTM EPS와 내재가치 세율에서 뺀다. 공시일 이전 시점에는 쓰지 않는다. **Fable이 FY2025 발표 "충당금 제외 시 13%"와 우리 계산(11.1%)이 어긋남을 잡았다** — 연간 제외액은 $14.30B라 4분기에 금액 미공시 환입 약 $1.63B가 있었다. 사용자 결정으로 이를 연간 세율에서 역산해 `derived: true` 항목으로 추가(EPS −$0.63, 13% 반올림 오차 ±$0.43B). 결과: PER 29.3 → 26.8, 세율 22.2% → 15.0%, 기본 내재가치 $456 → $511.
- **재고 없는 사업(사용자 결정)** — 재고 태그를 한 번도 낸 적 없는 회사는 재고 0(영업순환주기 = 매출채권 회수기간). 한때라도 낸 회사는 그대로(GOOGL처럼 끊긴 기간이 0으로 채워지지 않게). 매입채무는 `AccountsPayableTradeCurrent`를 두 번째 태그로 추가(META 2021~2026-03, 겹치는 날짜 값 같음, 다른 7장은 이 태그 없음).
- **우선주 2012년 값**은 0이라 EV에 영향 없음 — 낡은 EV 구성요소 필터는 META에는 불필요(필요한 카드가 나오면 그때).
- **비영업 자산(사용자 결정)** — 상장주식 $3.54B가 10-Q 공정가치 표에서 단기 시장성 증권 합계($74.8B) 안에 있어 비영업 자산·운전자본 차감에 두 번 들어갔고, 지분법 투자 $9.41B(Scale AI 등)는 빠져 있었다(Fable). `nonop_extra.json`에 META 항목(`EquityMethodInvestments` 추가, `exclude: EquitySecuritiesFvNi`)을 넣었다. 다른 7장은 점검 결과 해당 없음(NVDA 단기투자는 채권만, GOOGL·MSFT·TSM은 장기투자 태그, AMZN은 상장주식 태그 없음). 비영업 $24.29B → $30.16B.
- **판정** — 자기 이력 29.8(−1, 기준 30 바로 아래)·동종업 64.6(0)·현금흐름 1.52 "매우 비싸다"(−2) → 합계 −3 **고평가**. 두 칸 모두 경계라 가격·EPS가 조금만 움직여도 적정~고평가로 돌아갈 수 있다.
- **남은 과제(Fable 낮음)** — ① "최근 5년 성장"은 창 안 TTM 19분기(4.75년) CAGR이다(틀 공통, 카드 문구만 "약 5년(19분기)"로 고침). ② 동종업 점수의 입력(valuation_base)에 AMZN PCR 16.6(실제 FCF 적자)이 남아 있고, 다른 카드가 META를 비교할 때도 옛 EPS 기준이다 — 파이프라인 이식 때 정리. ③ META 매입채무에 설비투자 미지급금이 섞여 DPO 94일·CCC −65일이 부풀어 있다(점수는 DSO만 써서 영향 없음). ④ 이자보상배율은 단일 분기·자본화 이자 차감 후 기준.
- 뉴스: 9월 급등(+36%)은 SEC 공시가 아니라 Muse 출시(9/8, 반응 9/9)·앱스토어 1위(9/21)·Connect(9/23 장 마감 후 → 9/24)라 보도 출처(Meta Newsroom·Motley Fool·TechCrunch)를 썼다.

## TSLA — 총계만 내는 차입금·미획득 제한주·요구 마진 모드 (2026-09-25)

- **차입금** — 세부 태그(`LongTermDebtCurrent/Noncurrent`)가 2014-09에 끝나고 이후 `LongTermDebt`만 낸다(2014-12~2018-12는 LTD&CLO 보충이 비유동분만 잡고 있었다). "세부가 하나도 없을 때만 총계" 규칙이 옛 세부 태그 때문에 안 걸려 2018년 값이 쓰이고 있었다. 세부의 마지막 날짜 **뒤**는 총계로 채운다. us-gaap 정의상 LongTermDebt는 유동분 포함 총액이지만 TSLA는 비유동분만 태깅하므로(10-Q 확인), **`DEBT_NONCURRENT_ONLY`(CIK 목록)에 있는 회사만** 같은 날짜 `DebtCurrent`를 더한다(2026-06 $7.72B + $1.34B = 10-Q $9.06B). 목록에 없는 회사가 이 경로에 들어오면 경고를 찍는다(Fable). 9장 차입금 시계열 불변. 2016-12 LongTermDebt는 XBRL 단위 오류($5.9M)지만 5년 창 밖. SPCX도 LongTermDebt가 비유동분뿐일 가능성(실제 약 $39.4B)은 부분 카드 갱신 때 확인.
- **미획득 성과 제한주(사용자 결정)** — 목표를 채워야 획득되어 **희석 EPS에서도 빠지는** 주식만 뺀다(`v2/share_adjust.json`, `instant_series`가 결산일 기준 from~until 관측에서 차감). TSLA: 2025 CEO 성과 보상 423,743,904주(2025-11-06~), 2025 임시 보상 96M주(2025-08-03 부여 ~ 2026-04-21 몰수, Fable이 2025-09~2026-03 주식 수에 남은 것을 잡음). 3.95B → 3.53B(사이트 파이프라인 3.95B와 다름). 2018년 보상 행사분 286.5M주는 서비스 조건(2028-01)만 남고 희석 EPS에 포함되므로 그대로 둔다.
- **감가상각** — SEC 태그는 `Depreciation`뿐이라 회사 발표 "감가상각·상각·손상"(최근 4분기 $6.48B)보다 $0.9B 작아 EV/EBITDA가 약 10% 높게 나온다(이력은 같은 태그라 백분위는 자기 일관적). 툴팁에 적었다. 디지털 자산은 표준 태그 `CryptoAssetFairValueNoncurrent`가 있어 고정값 대신 태그로 넣었다(과거 추이 점에도 반영).
- **비영업 자산** — SpaceX 지분(공정가치 $3.01B)·비트코인($0.67B)은 표준 태그가 없어 `nonop_extra.json`에 10-Q 값을 `{name, value, end, filed}`로 적는다(공시일 이전 시점 제외, 같은 이름은 최신 값만).
- **본업 기준 문턱** — (세전 − 영업이익) ÷ 영업이익 19.3%로 20% 바로 아래라 공시 EPS를 쓴다(PER 350배). 영업외이익(SpaceX 평가이익·이자수익·비트코인)이 커서 다음 분기에 문턱을 넘을 수 있다.
- **내재가치** — 영업이익률 4.2%라 요구 마진 모드(87.9%). 낙관(3년 성장 3.3% · 현재 마진)이 세 시나리오 중 가장 낮고, 추이에서도 낮은 성장 > 기본 > 높은 성장인 점이 많다 — 이익률이 낮아 빨리 클수록 재투자가 이익을 넘는 모델 구조다. 카드 문구에 "이 모델은 아직 매출이 없는 사업을 값으로 매기지 않는다"고 적었다.
- **비교군** — 자동차 동종(GM·F·TM)은 valuation_base에 없어 빅테크 6종과 비교. META 값은 valuation_base(일회성 세금 미조정)가 아니라 META 카드 값을 썼다.
- **작업 사고** — 뉴스 항목 하나를 비탐욕 정규식으로 지우다 뒤쪽 카드 영역까지 지웠다. 카드를 `clone_card.py --force`부터 스크립트로 다시 만들어 복구했다 — **카드 안의 블록을 지울 때는 끝 표식이 유일한지 먼저 확인하거나, 생성 스크립트에서 빼고 다시 만든다.**

## 내재가치·종합 평가 개선 방향 (2026-09-25, team-assemble 토론 → 사용자 결정)

철학 조사(opus)·모델 진단(opus)·개선 설계(opus)·Fable 비판을 거쳤다. 계산 스크립트: 세션 scratchpad `diag.py`·`run2.py`·`critic_a.py`·`critic_b.py`.

- **진단** — 기본 시나리오의 성장 경로가 5년차에 이미 영구 2.5%(fade = i/(years−1))라 초과성장이 사실상 약 2년이다. 잔존 EV/NOPAT = (1 − g/ROIC)/(r − g) ≤ 1/0.075 = 13.3배(카드 9장 9.0~13.0배, 잔존 비중 70~79%), 시장 27~42배. 지렛대는 잔존 공식이 아니라 **성장 경로 모양**이다. 영업권 제외 +0~13%, 감가상각만 AVGO −4%(반대), ROIC 수렴 제거 +0~4%, 할인율 9% +15%·8% +35%(균일, 순위 불변), R&D 자본화 META +28%(상한 근사).
- **사용자 결정 ① 원칙 유지** — 10년 2단계를 넣어도 AAPL(≈2.5)·AMZN(≈2.4)·TSLA(≈15)는 "매우 비싸다"로 남는다(성장·자본수익 입력 때문). 버핏이 AAPL을 PER 10.6(2016)에 사고 비슷한 가격대(2023-24)에서 2/3를 판 판단과 같은 방향이므로 받아들이고, **모델 구조만 고친다**.
- **사용자 결정 ② 판정 유지 + "계산 어려움" 배지** — 판정 보류(기권)는 수학적으로 값이 무의미한 경우(투하자본 ≤ 0 등)로만 제한하고, 그 밖은 판정을 유지한 채 배지·사유·요구 마진을 나란히 보여 준다. 배지 신호는 채택 전에 기계식으로 고정한다(후보: 한계 ROIC < 할인율, 투하자본 ≤ 0, 실효세율 < 10%, 비영업자산 > 주주가치 30%, 요구 성장률 해 없음 — "비율 > 1.5" 자체는 신호가 될 수 없다).
- **실행 순서(각 단계 승인 후)** — ① 입력 버그: 성장률 COVID 기저효과(min(3년, 5년 CAGR) 또는 COVID 이전 기점), 유니버스 "매우 싸다" 상위(SPG 0.00·NCLH 0.05·TRMB 0.06·CCL 0.12) 원인 확인 ② 영구 세율을 본국 법정세율로 수렴(AVGO 실효 5% 영구 적용 버그, D1 뒤 AVGO 1.67) ③ 10년 2단계: 고정 성장 상한 20%, 고성장 3년 전 종목 동일, 10년차 ROIC → 할인율 완전 수렴(성장은 끝나는데 초과수익만 영구히 남는 모순 제거) ④ 채택 판단은 IC 관문이 아니라 **과거 시점 재현**(AAPL 2016-Q1 ≤0.9·2024-Q1 ≥1.1, META 2022-11 ≤0.9, TSLA 2021-11 >1.5, NVDA 2022-10)·**단계 보정표**(5단계별 126일 초과수익, 양끝 순서)·**엔진 단위검정**(ROIC = 할인율이면 성장 무관, ROIC → ∞면 13.33배) ⑤ 카드에 잔존 비중·계산 어려움 배지.
- **하지 않기로 한 것** — 비열등 ΔIC 관문(유효 표본 ≈3·높은 상관이라 통과 장치), "새로 싸진 무리 초과수익" 검정(표본 안 모멘텀), 분위 기반 성장 상한(분포 문턱과 모순, NVDA 판정이 한 문턱에 매달림), 과거 ROIC 연속 햇수로 고성장 기간 차등(대형주는 전부 최대라 무력), 영업권 제외 매출/자본(D2, 인수 매출은 남기고 자본만 지우는 모순), 국채+ERP 유동 할인율(시장 추종), R&D 자본화(보류). 할인율 10%·문턱 0.7/0.9/1.1/1.5 유지. 기존 백로그 "할인율/영점 재보정"은 이 결정으로 닫는다.
